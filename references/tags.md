# OpenTracks 标签码对照表

站内标签分三组，URL/检索写法固定为 `mXX` / `rXX` / `iXX`。同组多值是 **AND（交集）**，叠得越多结果越窄。
把中文需求翻成代码时，**情绪最多 1–2 个，曲风 1 个，乐器 1 个**，超过 3 个经常直接搜空。

## 中文需求 → 代码的常用映射

| 用户说法 | 建议组合 |
|---|---|
| 温暖治愈的日常 vlog | `--query "温かい 日常 優しい BGM"` ，不加标签或 `m03,m35` |
| 雨天 / 夜晚 / 城市孤独 | `--query "雨の夜 街 孤独"` + `m13` 或 `m04` + `r17` |
| 有格调的咖啡店 / chill | `m31` + `r27` 或 `r35` |
| 紧张追逐 / 悬疑 | `m34,m20` + `r30` |
| 史诗 / 预告片 | `m32` + `r29` + `r30` |
| 可爱小游戏 | `m09` + `r21` |
| 赛博 / 科技宣传片 | `m21` + `r17` |
| 纯钢琴、不要鼓 | `--tags i03 --exclude-tags i17` |
| 日式和风 | `r23` |
